# 실제 AI 감지 테스트 결과 (2026-10-15)

## 환경
- 클라우드 서버 CPU 4코어, GPU 없음
- 모델: `yolo11n-pose` (가장 가벼운 자세 인식 모델), 입력 640, 신뢰도 0.25
- 영상: 공개 낙상 데이터셋의 실제 요양시설 CCTV 영상 5개 (640×360, 25fps)
  - 출처: github.com/ambianic/fall-detection `videos/` (저장소에는 포함하지 않음)
  - 원본은 넘어진 직후 끝나므로, 무반응 판정 확인용으로 마지막 장면을 10초 정지 화면으로 늘려서 사용

## 1차 결과: 공개 모델 그대로 → 0/5 감지
서 있는 사람은 신뢰도 0.8~0.9로 잘 잡지만, **바닥에 쓰러진 사람은 거의 인식하지 못함**.
모델을 키워도(`s`, `m`), 일반 사람 인식 모델로 바꿔도 비슷했다.
공개 모델의 학습 데이터(COCO)에 누운 사람 사진이 적기 때문.

| 모델 | 쓰러진 뒤 장면에서 사람 인식 | 1장 처리 시간 |
|---|---|---|
| yolo11n-pose | 2 / 44 | 43ms |
| yolo11s-pose | 8 / 44 | 88ms |
| yolo11m-pose | 4 / 44 | 205ms |
| yolo11n (일반) | 2 / 44 | 40ms |
| yolo11s (일반) | 4 / 44 | 79ms |

## 보강: "넘어지는 동작 직후 인식 끊김" 판정 추가
- 서 있던 사람이 **누움 / 키 25% 이상 급감 / 박스가 옆으로 1.35배 이상 넓어짐** 중 하나를 보인 직후
- **화면 가장자리가 아닌 곳에서** 0.6초 이상 인식이 끊기면 → 쓰러짐
- 그 자리에서 다시 일어서는 모습이 잡히지 않고 8초 지나면 → 무반응 → 119

## 2차 결과: 4/5 감지
| 영상 | 넘어진 뒤 쓰러짐 판정까지 | 무반응(119) 판정 |
|---|---|---|
| 1 (탁자 짚고 숙인 채 넘어짐) | ❌ 못 잡음 | - |
| 2 (복도, 보행 중 넘어짐) | 0.6초 | ✅ |
| 3 (보행기 사용 중 넘어짐) | 1.0초 | ✅ |
| 4 (휴게실, 풍선 놀이 중 넘어짐) | 1.8초 | ✅ |
| 5 (로비, 강아지 산책 중 넘어짐) | 1.4초 | ✅ |

- 4번 영상의 허리 숙여 풍선 줍기, 5번 영상의 다른 사람 보행 등에는 **오탐 없음**
- 1번은 처음부터 몸을 숙인 자세라 '서 있다가 넘어짐' 패턴이 없음. 억지로 맞추면 숙이는 동작마다 오탐이 생겨서 보류

## 속도 (카메라 4대 동시, CPU 4코어)
- 카메라당 1장 약 155ms, **카메라당 초당 약 6.4장 분석**
- 맥북 M4/M5 GPU나 NVIDIA GPU에서는 훨씬 빠를 것으로 예상 (실측 필요)

## 한계와 다음 단계
- 테스트 영상 5개는 판단 기준을 확정하기에 적다. **현장 영상으로 더 검증해야 함**
- 쓰러진 사람을 직접 인식하는 **낙상 전용 모델 학습**(공개 낙상 데이터셋으로 추가 학습)을 하면 1번 같은 경우도 잡을 수 있고, 위치 표시도 정확해짐
- 넘어진 뒤 인식이 끊긴 경우 화면 표시는 '마지막으로 확인된 위치'라 실제 누운 자리와 조금 다를 수 있음
