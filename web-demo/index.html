    보이는 화면 우선 분석지금 화면에 없는 카메라는 느리게 분석해 기기 부담을 줄임
    절전 모드카메라당 초당 2장까지만 분석 (노트북 발열 감소)
    사람 박스 표시끄면 쓰러짐 표시만 보임
    모든 화면에서 안전모 검사끄면 공사장·웹캠 화면만 검사 (기기 부담 감소)
    낮을수록 애매한 자세도 잡지만 잘못 잡는 경우도 늘어남 (기본 0.25)
    기본 1.0초
    쓰러진 뒤 움직임 없으면 긴급 (기본 8초)
    기본 15초

    카메라 앞에서 동작을 여러 번 보여 주면 관절 움직임 패턴을 저장하고, 이후 같은 동작이 나오면 알아봄. 웹캠 칸(16번)에서 쓰는 것을 권장.

    준비
    저장된 동작
    높을수록 쉽게 인식(오인식 증가). 기본 1.6

    지금 동작하는 것

    • 사람·자세 인식 AI(YOLO11 pose)가 이 브라우저 안에서 15개 화면을 분석
    • 쓰러짐 → 즉시 신고 창 → 무반응 시 긴급 격상 → 자동 신고(시연 모드)

    웹캠 · 동작 학습

    • 16번 칸 📷 웹캠 연결 (GitHub Pages 주소나 localhost에서 열 때 동작, claude.ai 링크 페이지는 카메라 차단)
    • 동작 학습 탭: 이름·위험도·호출을 정하고 같은 동작을 3~5번 기록 → 저장 → 이후 같은 동작을 인식
    • 저장한 동작과 분석 기록은 이 브라우저에 남고, 파일로 내보내 친구와 공유 가능

    감지 종류

    • 쓰러짐 → 무반응 (119): 실제 낙상 영상 5개 중 4개 감지 검증
    • 싸움·폭행 의심: 몸이 겹친 2명의 빠른 팔 움직임 → '확인 필요' 알림, 15초 안에 다시 감지되면 112 신고 창. 공개 싸움 영상 기준 약 20% 감지·평상시 오탐 약 2% (규칙 기반이라 전용 모델로 개선 필요)
    • 안전모 미착용 (주의): 공개 안전모 감지 모델(Construction Site Safety, CC BY 4.0). 기본은 공사장·웹캠 화면만 검사
    • 학습 동작: 동작 학습 탭에서 기록한 동작

    아직 없는 것

    • 화재·연기 감지, 폭행 전용 학습 모델

    영상 출처

    • 공공장소: Surveillance Camera Fight Dataset (Aktı et al., 2019, MIT)
    • 요양병원: 공개 낙상 영상 github.com/ambianic/fall-detection (무반응 확인용으로 끝 장면 연장)
    • 공사장: 공개 PPE 감지 저장소 샘플 영상 (ppe-1~3)
