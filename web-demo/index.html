    무엇이 실제로 동작하나요?

    • 사람·자세 인식 AI(YOLO11 pose)가 이 브라우저 안에서 영상을 직접 분석합니다. 서버로 영상을 보내지 않습니다.
    • 쓰러짐 → 무반응 → 119 카운트다운 판단 로직은 실제 백엔드와 같은 규칙입니다.
    • 신고는 시연 모드라 실제로 발송되지 않고 기록만 남습니다.

    조작

    • 위쪽 숫자로 분할 수 변경, 가로×세로 직접 입력 가능
    • 화면 클릭 → 확대, ‹ › 버튼·키보드 ←/→·스와이프로 넘기기, Esc로 닫기
    • ＋ 내 영상으로 테스트: 휴대폰으로 찍은 영상(전신이 보이게 서 있다가 바닥에 눕기)을 올리면 그 영상도 분석합니다
    • 감지 설정 탭에서 판정 시간과 민감도를 바꿔 볼 수 있습니다

    샘플 영상

    • 공개 낙상 데이터셋(github.com/ambianic/fall-detection)의 요양시설 CCTV 영상 4개
    • 원본이 넘어진 직후 끝나서 무반응 판정을 볼 수 있게 마지막 장면을 12초 정지 화면으로 늘렸습니다

    알아둘 점

    • 공개 AI 모델은 바닥에 쓰러진 사람을 잘 인식하지 못합니다. 그래서 "넘어지는 동작 직후 화면 가운데서 인식이 끊김"도 쓰러짐으로 보고, 마지막 위치에 FALL? 박스를 그립니다.
    • 분석 속도는 이 기기의 CPU 성능에 따라 다릅니다. 각 화면 오른쪽 위에 초당 분석 장수가 표시됩니다.
